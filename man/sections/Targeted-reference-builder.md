# Targeted Reference Builder

The `targeted-reference-builder` module is an experimental bridge between shotgun taxonomic profiling and ancient-DNA damage authentication.

It starts from a Kraken2/Bracken abundance table, selects the most abundant taxa, downloads a small RefSeq genome set with the NCBI Datasets CLI, combines the downloaded genomes into a FASTA file, and builds BWA/samtools indexes.

## Intended Workflow

```text
Kraken2-Bracken
-> targeted-reference-builder
-> map-to-targeted-reference
-> metaDMG
```

This keeps the reference database small enough for local SLIM deployments. It is not meant to replace a carefully curated ancient-DNA reference database.

## Input

### Kraken2/Bracken Relative-Abundance Table

Default:

```text
kraken2_bracken_relative_abundance.tsv
```

The first implementation expects the matrix generated by the SLIM `kraken2-bracken` module. It must contain at least:

```text
name    taxonomy_id    taxonomy_lvl    sample...
```

## Outputs

### Targeted Reference FASTA

Default:

```text
targeted_reference.fna
```

Combined FASTA file containing the downloaded reference sequences. FASTA headers are rewritten to include the NCBI taxid, which keeps reference names stable for mapping and metaDMG.

### Reference Manifest

Default:

```text
targeted_reference_manifest.tsv
```

Table listing the selected taxid, taxon name, rank, maximum abundance, assembly-selection mode, source file, and rewritten sequence ID.

### acc2tax Table

Default:

```text
targeted_reference.acc2tax.tsv
```

Two-column table mapping rewritten reference sequence IDs to NCBI taxids. This can be used by `metaDMG` in taxid mode.

### Reference Archive

Default:

```text
targeted_reference.tar.gz
```

Archive containing the FASTA, BWA index, FASTA index, manifest, and selected-taxa table.

## Parameters

| Parameter | Default | Meaning |
| --- | --- | --- |
| Kraken2/Bracken rank | `S` | Taxonomic rank to select from the Bracken matrix. |
| Minimum relative abundance | `0.001` | Taxa must reach this abundance in at least one sample. |
| Maximum taxa | `25` | Caps the number of taxa downloaded. |
| Maximum genomes per taxon | `1` | Caps the number of genome FASTA files used per selected taxon. |
| Assembly choice | `reference_then_representative` | Tries reference genomes first, then representative genomes, then complete RefSeq genomes. |

## Notes

This module needs internet access from the container because it calls NCBI Datasets during the SLIM run.

For ancient DNA, keep `Maximum taxa` and `Maximum genomes per taxon` conservative at first. Large targeted references make mapping slower and can create large BAM files.
