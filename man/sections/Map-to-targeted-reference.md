# Map to Targeted Reference

The `map-to-targeted-reference` module maps FASTQ reads to a targeted reference FASTA and produces BAM files with `MD:Z` tags for metaDMG.

It is designed to consume the reference generated by `targeted-reference-builder`.

## Input

### Input Mode

| Mode | Use case |
| --- | --- |
| Single-end reads | One FASTQ file per sample. |
| Paired-end reads | One forward and one reverse FASTQ file per sample. |

Inputs can be normal files or wildcard groups created by `wildcard-creator`.

### Targeted Reference FASTA

Default:

```text
targeted_reference.fna
```

This should usually come from the `targeted-reference-builder` module.

## Outputs

### Output BAM Pattern

Default:

```text
*_targeted.bam
```

The `*` is replaced by each sample name. BAM indexes are created beside the BAM files as `.bai`.

### Mapping Archive

Default:

```text
targeted_reference_mapping.tar.gz
```

Archive containing mapping statistics, fastp reports, and the BAM/BAM index files.

## Parameters

| Parameter | Default | Meaning |
| --- | --- | --- |
| Mapper | `bwa aln` | `bwa aln` is often better for short/degraded ancient DNA reads. `bwa mem` is available for modern or longer reads. |
| Minimum mapping quality | `0` | Optional MAPQ filter applied before metaDMG. |
| Trim adapters and low-quality bases with fastp | enabled | Runs fastp before mapping. Paired-end runs use `--detect_adapter_for_pe`. |

## Processing

The module:

1. Builds missing BWA and FASTA indexes if needed.
2. Optionally trims FASTQ files with fastp.
3. Maps reads with `bwa aln`/`samse`/`sampe` or `bwa mem`.
4. Sorts BAM files with samtools.
5. Runs `samtools calmd` to add `MD:Z` tags required by metaDMG.
6. Produces `flagstat` and `idxstats` reports.

## Ancient-DNA Notes

For short ancient DNA reads, start with `bwa aln`, fastp enabled, and a low or zero MAPQ threshold. Raise MAPQ only after checking how many reads remain.
